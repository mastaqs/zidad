# Zidad — زِدَاد

Arabic RTL digital-services marketplace frontend.

## Experience
- Inline three-state custom request composer with local drafts.
- Search, category tabs, delivery and price filtering.
- Independent editorial collections for shops, charities, and brands.
- Inline service details, provider comparison, and simulated order review.
- Device-local bookmarks, orders and preview profile. No backend transactions.
